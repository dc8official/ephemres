**Release Tag**: `v3.3.2.v`

**Release Date**: October 2026

## Executive Summary

Ephemres `v3.3.2.v` represents a foundational architectural milestone: the full execution of the **Vertical Integration Architecture**. 

Modern Python server applications frequently suffer from severe software bloat, supply chain attack surface, and dependency rot caused by deep, unvetted trees of external frameworks and C-extension wheels. In `v3.3.2.v`, Ephemres completely eliminates 13 heavy external runtime frameworks, ORMs, and daemon dependencies (`fastapi`, `starlette`, `pydantic`, `sqlalchemy`, `alembic`, `redis`, `psycopg2-binary`, `httpx`, `jinja2`, `weasyprint`, `pypdf`, `psutil`, and `argon2-cffi`), replacing them with **13 zero-dependency native engines** authored directly within `backend/app/core/`.

The entire platform now runs on pure **Python 3.12+ Standard Library** plus just two minimal, production-grade drivers:
1. `uvicorn`: High-performance ASGI HTTP server.
2. `asyncpg`: Zero-reflection PostgreSQL binary protocol driver.

All external daemons except TimescaleDB/PostgreSQL have been eliminated: Redis has been replaced with **FastStore**, a pure-stdlib in-RAM `/dev/shm` SQLite WAL engine providing sub-millisecond key-value, set, sorted set, stream shock-absorption, and inter-process pub/sub messaging.

## The 6 Stages of Vertical Integration

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        Ephemres Vertical Integration Journey                           │
│                                                                                        │
│  Stage 1 ➔ Foundational Zero-Dependency Utilities (Crypto, HTTP, Netlink, Template)   │
│  Stage 2 ➔ Document Generation & System Telemetry (Pure PDF Engine, /proc Diagnostics) │
│  Stage 3 ➔ Zero-Dependency Raw Socket ICMP Engine (Native IPPROTO_ICMP Socket)         │
│  Stage 4 ➔ In-RAM FastStore Engine (/dev/shm SQLite WAL Mode replacing Redis)          │
│  Stage 5 ➔ Framework Elimination (Native Migrator, Schema, ASGI Router, Async ORM)     │
│  Stage 6 ➔ Layer 0 Consolidation & Native Ephemres Identifier Renaming                 │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### Stage 1: Foundational Zero-Dependency Utilities
* **Cryptographic Key Derivation (`backend/app/core/crypto.py`)**: Replaced `argon2-cffi` and complex C-compiler toolchains with pure-stdlib **Scrypt** key derivation (`hashlib.scrypt`, `$scrypt$n=16384,r=8,p=1$`) with constant-time signature verification (`hmac.compare_digest`). During upgrades or database restores from legacy versions (`v3.1.35s`, `v3.3.0`, `v3.3.1n`) containing `$argon2id$` hashes, `app.reset_legacy_passwords` replaces legacy password hashes with temporary scrypt passwords with `must_change_password = TRUE` and writes a root-only credentials report to `/opt/ephemres/legacy_password_resets.txt`.
* **ASN.1 DER X.509 Certificate Parser (`backend/app/core/der.py`)**: Replaced `cryptography.x509` with a zero-dependency ASN.1 DER parser extracting leaf certificate validity dates (`notBefore`, `notAfter`) and subject alternative names directly from binary TLS socket handshakes for synthetic HTTPS health checks.
* **RFC-Compliant SSRF-Hardened HTTP Client (`backend/app/core/http_client.py`)**: Replaced `httpx` with a zero-dependency async socket HTTP client (`asyncio.open_connection`, `ssl.create_default_context`). Enforces socket-level SSRF defense, resolving DNS queries and blocking RFC 1918, RFC 3927 (AWS/GCP metadata `169.254.169.254`), and loopback ranges prior to TCP handshake.
* **Pure Linux RTNETLINK Parser (`backend/app/core/netlink.py`)**: Replaced `psutil.net_if_addrs()` with an in-tree Linux kernel Netlink socket (`socket.AF_NETLINK`, `socket.NETLINK_ROUTE`) emitting `RTM_GETADDR` requests and parsing binary `nlmsghdr`, `ifaddrmsg`, and `rtattr` structures.
* **Jinja2-Compatible Template Compiler (`backend/app/core/template.py`)**: Pure-stdlib template rendering engine supporting variable interpolation (`{{ var }}`), block conditionals (`{% if %}`), block loops (`{% for %}`), block inheritance (`{% block %}`, `{% extends %}`), default filters (`| default(...)`), and context-aware HTML escaping.
* **Systemd Watchdog Client (`backend/app/core/watchdog.py`)**: Zero-dependency UNIX domain datagram socket client connecting to `$NOTIFY_SOCKET` to transmit `READY=1`, `STATUS=...`, and periodic `WATCHDOG=1` heartbeats without external dependencies.
* **Structured Logger & Bounded Rotation (`backend/app/core/logging.py`)**: In-tree structured logging system configuring standard library loggers with RFC 3339 timestamps and bounded file rotation, replacing external logging packages.

### Stage 2: Elimination of `psutil`, `weasyprint`, and `pypdf`
* **Pure-Stdlib PDF Compliance Engine (`backend/app/core/pdf.py`)**: Replaced WeasyPrint, Pango, Cairo, and PyPDF with a zero-dependency PostScript/PDF binary emitter. Directly synthesizes ISO A4 compliant documents with vector styling, typography matrices, multi-page headers/footers, and Base64 corporate branding.
* **Native Host Diagnostics (`backend/app/services/diagnostics.py`)**: Replaced `psutil` CPU, memory, and disk telemetry with direct asynchronous reading of Linux `/proc/stat`, `/proc/meminfo`, `/proc/loadavg`, `/proc/net/dev`, and `os.statvfs`.

### Stage 3: Zero-Dependency Raw Socket ICMP Engine
* **Raw Socket Ping (`monitoring/ping.py`)**: Implemented direct raw socket ICMP probing (`socket(AF_INET, SOCK_RAW, IPPROTO_ICMP)`) with 16-bit one's complement checksum calculation (`struct.pack("!BBHHH", 8, 0, checksum, ident, seq)`), precise microsecond monotonic timing (`time.perf_counter`), and transparent fallback to standard unprivileged ICMP datagram sockets (`IPPROTO_ICMP` unprivileged socket) or system ping.

### Stage 4: In-RAM FastStore Storage Engine (`backend/app/core/faststore.py`)
* **Elimination of `redis-server` and `aioredis`**: Designed a pure-stdlib, in-RAM `/dev/shm` SQLite-backed storage engine configured in `WAL` (Write-Ahead Logging) mode with `synchronous=OFF`, `cache_size=-65536` (64MB memory cache), and multi-threaded `RLock` isolation.
* **Redis-Compatible Async Protocol Interface**: Implements `FastStoreClient` (`Redis = FastStoreClient`):
  * **Key-Value Store**: `get`, `set` (with `ex`, `px`, `nx`, `xx`), `delete`, `exists`, `incr`, `expire`, `ttl`, `keys`, `scan_iter`.
  * **Set Store**: `sadd`, `srem`, `smembers`, `scard`, `sismember`.
  * **Sorted Sets (ZSET)**: `zadd`, `zrem`, `zrangebyscore`, `zrevrangebyscore`, `zremrangebyscore`, `zcard`, `zremrangebyrank` supporting sliding 24-hour unmatched exporter discovery.
  * **High-Throughput Streams**: `xadd`, `xreadgroup`, `xack`, `xtrim` with bounded sliding-window trimming, powering `ephemres-flowd` ingestion buffer (`stream:netflow:raw`).
  * **Pub/Sub Broker**: Thread-safe, non-blocking `pubsub()` supporting `subscribe`, `unsubscribe`, and async streaming iteration across worker processes.

### Stage 5: Elimination of Framework Layer (`fastapi`, `starlette`, `pydantic`, `sqlalchemy`, `alembic`)
* **Native Async Migration Engine (`backend/app/core/migrator.py`)**: Built an in-tree schema migration tool replacing Alembic and psycopg2. Compiles and executes all 12 platform revisions sequentially directly over `asyncpg`, recording executed versions in the `alembic_version` state table.
* **Zero-Dependency Schema Validation Engine (`backend/app/core/schema.py`)**: Pure-stdlib type validation and JSON serialization engine implementing `SchemaModel` (`BaseModel = SchemaModel`), `Field`, `validator`, `field_validator`, `ConfigDict`, and `to_camel`.
* **Zero-Dependency ASGI 3.0 Application Engine (`backend/app/core/asgi.py`)**: Implemented `EphemresApp` (`FastAPI = EphemresApp`) and `APIRouter` supporting path parameter routing, typed query/body injection, dependency resolution (`Depends`), lifespan context management, CORS middleware, and custom exception handlers.
* **Zero-Dependency Async ORM & Query Builder (`backend/app/core/orm.py`)**: Built a full async ORM over `asyncpg`, providing `DeclarativeBase`, `Column`, SQL types (`Integer`, `String`, `DateTime`, `Boolean`, `Float`, `JSONB`, `UUID`), relationship navigation (`relationship`, `foreign_keys`), query compilers (`select`, `insert`, `update`, `delete`, `func`, `case`, `text`, `or_`), and a Unit-of-Work `AsyncSession`.

### Stage 6: Layer 0 Consolidation & Native Identifier Renaming
* **Layer 0 Core Reorganization**: Moved all low-level infrastructure modules into `backend/app/core/`, establishing a clean two-layer backend where `app/core/` houses foundational engines and `app/services/` houses pure domain logic.
* **Native Ephemres Identifiers**: Replaced third-party naming remnants with native Ephemres identifiers (`FastStoreClient`, `EphemresApp`, `SchemaModel`, `FastStoreSettings`, `FastStoreSessionStore`, `FastStoreEventBroker`, `get_flow_store`), preserving backward-compatibility aliases for seamless testing.
* **Compatibility Shim Retirement**: Deleted legacy shim directories (`backend/{fastapi,starlette,pydantic,sqlalchemy,alembic,redis}`), proving zero reliance on external framework stubs.

### 2.5 Frontend Vertical Integration
* **Zero-Dependency Native `fetch` Client (`frontend/src/services/api.js`)**: Eliminated `axios` in favor of a native browser `fetch` wrapper featuring `AbortController` timeouts, automatic query-string serialization, Blob/PDF binary support, and 401 session interceptors.
* **100% Self-Hosted Local Fonts & Icons**: Replaced external Google Fonts and CDN dependencies with locally bundled `@fontsource/inter`, `@fontsource/jetbrains-mono`, and `primeicons` `.woff2` font files for strict air-gapped network compliance.

## Upgrade & Migration Runbook

Upgrading an existing installation (`v3.3.0` or `v3.3.1n`) to `v3.3.2.v` is fully automated by `deploy/upgrade.sh` with **zero historical data loss**:

```bash
cd /opt/ephemres
git pull origin v3.3.2v
sudo ./deploy/upgrade.sh
```

### What Happens During the Upgrade:
1. **Automated Database Backup**: A full SQL dump is created at `/var/backups/ephemres/`.
2. **Daemon Retirement**: Stops and disables `redis-server` (if installed on the host).
3. **Dependency Pruning**: Installs the lean 2-package virtualenv (`uvicorn`, `asyncpg`) in under 3 seconds.
4. **Native Migrations**: Executes `migrator.py` to verify and align all TimescaleDB hypertables, rollups, and constraints.
5. **Asset Compilation**: Builds the optimized Vue 3 production bundle displaying `v3.3.2.v`.
6. **Service Supervision**: Restarts `ephemres-api`, `ephemres-engine`, and `ephemres-flowd` under systemd.
7. **Verification**: Queries `/api/v1/version` and `/api/v1/health` to confirm operational readiness.
